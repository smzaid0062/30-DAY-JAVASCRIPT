🚀 Day 01 — JavaScript Introduction: Practice Questions

Since Day 1 is about getting comfortable with JavaScript and console.log(), start with these 5 practical questions:

1️⃣ Print Your Introduction

Write a JavaScript program that prints:

My name is Zaid.
I am learning JavaScript.
This is Day 1 of my 30 Days of JavaScript Challenge.

Concept: console.log()

2️⃣ Print Your Favorite Things

Print your:

Name
Favorite programming language
Favorite technology
Dream job

Example:

Name: Zaid
Favorite Language: JavaScript
Favorite Technology: React
Dream Job: Full Stack Developer

Concept: Multiple console.log() statements.

3️⃣ Print a Welcome Message

Create a program that prints:

==============================
   Welcome to JavaScript 🚀
==============================
Day 1 of 30 Days Challenge
Let's Start Coding!

Concept: console.log() and formatting.

4️⃣ Print Your Daily Learning Goal

Print a message describing what you want to learn today.

Example:

Today's Goal:
Learn the basics of JavaScript
and understand how JavaScript
works with HTML.

Concept: Multiple lines and strings.

5️⃣ Create Your Developer Profile

Use console.log() to display a mini developer profile:

===== Developer Profile =====

Name: Zaid
Role: Full Stack Developer
Skills: HTML, CSS, JavaScript, React
Learning: JavaScript
Challenge: 30 Days of JavaScript

=============================

Concept: Combining multiple console.log() statements.
